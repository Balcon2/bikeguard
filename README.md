# Smart Bike Airbag 

An open-source prototype for an ML-based bicycle and e-bike crash detection system.

## Goal

Detect potential crashes in real time using motion sensors and TinyML, with the long-term goal of developing a reusable bike airbag system.

## Hardware

- ESP32-S3
- BMI270 IMU
- SSD1306 OLED
- KY-003 Hall sensor
- Breadboard & jumper wires

## Software

- MicroPython
- Python
- scikit-learn
- TinyML

## Status

Early prototype — currently focused on collecting sensor data and developing the crash detection model.

> **Safety:** This is an experimental prototype and is not a certified safety device.# bikeguard
